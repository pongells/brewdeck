Install it

No soldering, no wiring, nothing on the machine reflashed: flash a spare screen over USB and pick your Wi-Fi on it. Run it with a headless machine or with the built-in screen tucked away; editing profiles, settings and maintenance stay in the machine's web UI.

What you need

  • A 4.3″ Sunton ESP32-8048S043-style screen (ESP32-S3, 800 × 480, touch, USB-C). The Guition JC4880P443 (ESP32-P4) works too, experimentally.
  • A Gaggiuino machine with its Wi-Fi web UI, on the same 2.4 GHz network as the screen.
  • A Mac or Linux computer with a USB cable and esptool. On Windows the scripts are untested; WSL may work.
Use a spare screen. Never flash the screen fitted to your machine: on a Gaggiuino Gen 3 machine it also runs the machine's Wi-Fi and web UI, which Brewdeck needs.

How it goes

  1. Download the package for your screen from the releases.
  2. Back up the screen's flash: the only way back to its original firmware.
  3. Flash it with the script in the package. It checks the chip and the backup first.
  4. Choose your Wi-Fi on the screen. It finds the machine by itself.

How it works

Brewdeck is a separate touchscreen. It is not wired to the machine: it reads it over Wi-Fi through Gaggiuino's documented REST and WebSocket API. Its firmware has three layers, each replaceable on its own; the machine's firmware stays as it is.

  1. UIThe screens above. Any graphics library; Brewdeck's own uses LVGL 9. It talks to the core through one header, brewdeck_core.h.
  2. CoreWi-Fi, finding the machine, live data, shots, settings. The only part that sends anything, and only what the web UI's dashboard sends.
  3. BoardOne folder per screen model: the Sunton ESP32-S3 4.3″ (800 × 480), and an experimental Guition ESP32-P4.
  4. MachineGaggiuino's own firmware, untouched. On this page it is fake: it replays a recorded shot and steam session, and answers profile, weight and temperature changes.

Build on it

Gaggiuino's network API makes room for other screens and interfaces; Brewdeck is one, and a place to start your own. Because the layers are separate, a new look does not touch the network code, and a new screen does not touch the interface.

Write your own interface

Start from the 150-line example interface (MIT licensed), try it against this same fake machine on your computer, then build it into the firmware. Four functions and one header are all it needs.

Bring it to another screen

A board folder provides the panel, touch, backlight and memory; the core and the interface stay the same. The ESP32-P4 port was done this way. No step-by-step guide yet: ask in the GitHub discussions.
