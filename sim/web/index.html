A brewing screen for Gaggiuino

Brewdeck is an unofficial Wi-Fi touchscreen for brewing on Gaggiuino machines, and a base for trying your own screens and interfaces on Gaggiuino's network API.

The screen's real interface, built for the browser, against a fake machine that replays a recorded shot and steam session. Click or tap the screen like the touchscreen; nothing here connects to a coffee machine.

On your machine

Flash a spare screen over USB and pick your Wi-Fi on it: no soldering, no wiring, nothing on the machine reflashed. Run it with a headless machine (one without its own screen) or with the built-in screen tucked away.

What you need

  • A 4.3″ touchscreen, one of two tested models: the Sunton ESP32-8048S043-style (ESP32-S3, 800 × 480) or the Guition JC4880P443 (ESP32-P4, 480 × 800 shown in landscape).
  • A Gaggiuino machine with its Wi-Fi web UI, on the same 2.4 GHz network as the screen.
  • A Mac or Linux computer with a USB cable and esptool.

Use a spare screen. Never flash the screen fitted to your machine: on a Gaggiuino Gen 3 machine it also runs the machine's Wi-Fi and web UI, which Brewdeck needs.

How it goes

  1. Download the package for your screen from the releases.
  2. Back up the screen's flash: the only way back to its original firmware.
  3. Flash it with the script in the package. It checks the chip and the backup first.
  4. Choose your Wi-Fi on the screen. It finds the machine by itself.

Make your own

Brewdeck reads the machine over Wi-Fi through Gaggiuino's documented API, and its firmware is in layers you can replace one at a time: a new look does not touch the network code, a new screen does not touch the interface.

  1. UIThe screens above, LVGL 9 here, any graphics library in yours.
  2. CoreWi-Fi, the machine, live data, shots, settings. The only part that sends anything.
  3. BoardOne folder per screen model: panel, touch, backlight, memory.
  4. MachineGaggiuino's own firmware, untouched (here, a fake one).

An interface is four functions

extern "C" const bd_ui_desc BD_UI = {"myui", "1.0", 1};
void bd_ui_init(void);                // once: build the screens
void bd_ui_tick(uint32_t now_ms);     // every pass: draw what changed
void bd_ui_event(const bd_event *e);  // shot point, notice, answer
void bd_ui_wake(void);                // turn the screen on

Start from the 150-line example interface (MIT licensed) and try it against this same fake machine on your computer. Ideas, bugs and ports are welcome in the discussions.
