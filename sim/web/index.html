Brewdeck is an unofficial Wi-Fi touchscreen for Gaggiuino machines. It is not made by or affiliated with the Gaggiuino project.

This page runs the same interface code as the screen, compiled to WebAssembly. The machine is fake: it replays a recorded shot and a recorded steam session, and answers profile, weight and temperature changes. Nothing leaves your browser.
